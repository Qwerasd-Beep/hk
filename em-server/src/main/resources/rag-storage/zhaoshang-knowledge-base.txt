招商服务平台知识库文档
					
					一、系统总体介绍
					
					招商服务平台是面向地方招商引资管理部门的一体化数字化业务系统，用于支撑外资企业监测、地方项目申报、中介机构管理、招商项目审批以及系统基础数据维护等日常工作。
					平台采用前后端分离架构：后端基于 Spring Boot 3、Spring AI、MyBatis 开发，数据库使用 MySQL，缓存与向量知识库使用 Redis；前端基于 Vue 3 与 Element Plus 开发。
					平台对外提供统一的 Web 访问入口，业务人员通过账号登录后，依据所属角色和菜单权限使用相应功能模块。
					平台的核心业务模块包括：外资企业信息管理、地方项目信息管理、中介机构管理、审批流程管理、数据字典管理，以及用户、角色、菜单、权限等系统管理功能。
					平台还集成了 AI 能力，包括智能对话、AI 文生图、AI 文生音、文本向量化、基于 Redis 向量数据库的语义检索和 RAG 知识库问答。
					
					二、外资企业信息管理
					
					外资企业信息管理模块用于登记和维护在本地区投资设立的外商投资企业档案，对应系统中的外资企业信息表。
					外资企业档案的主要信息字段包括：企业代码、企业名称、企业状态、企业类型、新批或变更标识、行业门类、所属行业、行业代码、是否高技术产业、统计部门。
					外资企业的设立与投资信息包括：成立日期、设立方式、企业地址、经营范围、投资总额、注册资本、外商出资金额、外商出资增减情况。
					外资企业的投资方信息包括：投资者名称、国别或地区、资金来源地、出资比例。
					外资企业的联系方式包括：联系人、固定电话、联系电话、邮箱。
					每条外资企业记录还会记录录入时间、录入人、录入人部门 ID、数据来源，并通过是否已删除字段实现逻辑删除，避免数据被物理清除。
					外资企业与企业类型表为一对一关联，通过企业类型对企业进行分类管理。
					业务人员可以在外资企业信息管理模块中新增、修改、查询、删除（逻辑删除）企业档案，并支持按企业名称、国别地区、所属行业等条件进行组合查询和分页展示。
					
					三、地方项目信息管理
					
					地方项目信息管理模块用于申报和跟踪地方投资建设项目，记录项目从申报、审批到开工建设、建成投产的全过程基本信息。
					项目基本信息包括：项目代码、项目名称、项目类型、建设性质、所属行政区划代码、是否外商投资或境外投资、项目属性、有效标识。
					项目时间与投资信息包括：拟开工时间、拟建成时间（按年份记录）、总投资额、总投资额折合美元及使用汇率、项目资本金及其折合美元和汇率。
					项目建设信息包括：建设地点、建设地点详情、国标行业、所属行业、建设规模及内容、土地获取方式、总用地面积、总建筑面积、是否新增设备、拟进口设备数量及金额。
					涉及境外或外商投资的项目，还需要填写投资方式、中方投资额、境外投资项目投资方式、并购安排、并购后经营方式及经营范围、提供交易双方情况等信息。
					涉及国家安全的项目需要标注是否涉及国家安全，并填写安全审查决定文号；项目还需记录投资项目目录编码、适用产业政策条目类型及条目。
					当总投资额为零时，必须填写总投资额为零时说明；项目申报后系统记录申报时间。
					业务人员可在该模块中进行项目信息的录入、修改、删除、条件查询与分页查看，并可通过项目代码关联后续的审批办理信息。
					
					四、中介机构管理
					
					中介机构管理模块用于维护为招商引资工作提供专业服务的中介代理机构信息。
					中介机构档案字段包括：中介机构名称、中介机构证照类型、中介机构证照号码、法定代表人。
					中介机构的联系人信息包括：联系人名称、联系电话、联系手机、联系人邮箱、传真、通讯地址。
					中介机构记录通过有效标识字段控制启用和停用状态，有效标识的可选取值来源于系统数据字典，不再使用的机构可将有效标识置为停用。
					业务人员可以在该模块中新增、编辑、查询中介机构，在招商项目对接过程中选择相应的中介机构参与服务。
					
					五、审批流程管理
					
					审批流程管理模块用于管理招商项目和相关业务的审批办理过程，记录每一个审批事项的办理状态和意见。
					审批办理信息包括：项目代码、审批事项 ID、办理处室、办理状态、办理意见、办理时间。
					每条审批记录关联所属人（ownerId），系统将来通过该字段进行数据权限控制，使业务人员只能看到自己权限范围内的审批数据。
					审批记录中的有效标识同样关联数据字典，用于标识记录是否有效。
					一个项目可以按照经办处室依次经过多级审批，每一级审批都会留下办理处室、办理状态、办理意见和办理时间，实现审批全程留痕。
					业务人员可以在系统中查看项目当前的审批进度、历史审批意见和每个节点的办理时间。
					
					六、数据字典管理
					
					数据字典分为字典类型和字典项两级，用于统一管理系统中的各类枚举和可配置选项。
					字典类型用于定义一类数据的分类，例如企业状态、办理状态、有效标识、行业分类等；字典项是字典类型下的具体可选值。
					中介机构的有效标识、审批记录的有效标识等字段都关联字典项，业务界面以下拉框形式展示，保证全系统口径统一。
					当业务选项发生变化时，由管理员在数据字典管理中维护，无需修改程序代码。
					
					七、用户、角色、菜单与权限管理
					
					系统管理模块包含用户信息管理、角色管理、菜单管理和权限管理。
					用户信息用于维护登录账号和人员资料；角色用于聚合一组权限；菜单用于控制系统左侧导航和页面访问；权限用于控制按钮和数据操作。
					用户通过绑定角色获得对应的菜单和操作权限，支持一个用户拥有多个角色。
					系统通过 JWT 令牌进行登录认证，前端登录成功后保存令牌，后续请求在请求头中携带令牌完成鉴权。
					系统管理员账号由各单位信息化部门统一开通；用户首次登录后必须修改初始密码；忘记密码不支持自助找回，需要联系管理员重置。
					
					八、常见问题与操作指引
					
					问：系统的技术支持方式是什么？答：技术支持热线为 400-888-6666，服务时间为工作日 9:00 至 18:00，非工作时间可通过单位信息化部门留言反馈。
					问：登录时提示账号或密码错误怎么办？答：请先确认账号和密码输入正确，注意区分大小写；连续无法登录时联系系统管理员核对账号状态或重置密码。
					问：忘记登录密码怎么办？答：系统不支持自助找回密码，请联系系统管理员重置，重置后使用初始密码登录并立即修改为新密码。
					问：外资企业信息录入后可以删除吗？答：系统采用逻辑删除机制，删除操作只会把是否已删除字段标记为已删除，数据仍保留在数据库中，可用于后续统计和追溯。
					问：为什么有些下拉选项在不同模块中是一致的？答：这些选项统一来自数据字典，例如有效标识、办理状态等，由管理员集中维护，保证全系统数据口径一致。
					问：如何查看一个招商项目的审批进度？答：在地方项目信息或审批流程模块中通过项目代码查询，可以看到该项目每个审批节点的办理处室、办理状态、办理意见和办理时间。
					问：项目总投资额为零时能否提交申报？答：可以提交，但必须如实填写总投资额为零时说明。
					问：AI 知识库问答回答的依据是什么？答：AI 助手通过向量检索从本知识库和已入库的业务文档中召回相关内容，并仅依据这些内容回答问题；如果知识库中没有相关信息，会明确告知未找到，不会编造答案。
					问：如何让 AI 助手掌握新的业务知识？答：管理员可以将整理好的业务说明文本导入系统，系统会自动对文本进行切片、向量化并存入 Redis 向量数据库，之后 AI 问答即可检索使用这些知识。
